# Legacy Blueprints & UDT Prototypes (Frozen)

This directory holds the archived `0.1.0`–`0.2.0` declarative `.focaloop.yml` blueprints and `GalaxyUserTool` (`galaxy_udt.yml`) prototypes retained for reference and backward-compatible unit tests.

Starting in `0.3.0`, the maintained Galaxy tool surface is the `tools-iuc` XML suite under [`tools/focaloop/`](../tools/focaloop/):

- `tools/focaloop/expressionloop.xml`
- `tools/focaloop/variationloop.xml`
- `tools/focaloop/geneloop.xml`
- `tools/focaloop/focaloop_query.xml`
- `tools/focaloop/macros.xml` and `tools/focaloop/.shed.yml`
